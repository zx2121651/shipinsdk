# VFX Engine SDK 功能文档 (Functional Specification)

## 1. 产品定位
VFX Engine 是一款专为移动端（首发 Android）设计的跨平台、高性能短视频与特效渲染引擎。系统致力于提供类似“剪映 (CapCut)” 的底层技术支持，使得上层业务能够轻松实现极低延迟的摄像头预览、复杂的节点式特效渲染以及带音视频完美同步的 MP4 硬件导出。

## 2. 核心功能特性

### 2.1 实时摄像头预览 (Live Camera Preview)
* **功能描述**：引擎支持直接接管设备的硬件摄像头画面，并实时渲染至设备屏幕。
* **特性亮点**：
  * **零拷贝 (Zero-Copy)**：视频流完全在 GPU 显存内流转，不占用 CPU 计算资源。
  * **高帧率**：借助独立渲染线程，预览帧率紧跟摄像头硬件帧率（通常为 30fps/60fps），完全不受 UI 线程卡顿影响。

### 2.2 节点式特效渲染图 (RenderGraph Filters)
* **功能描述**：画面在渲染上屏前，会经过一系列基于着色器 (Shader) 的特效滤镜处理。
* **内置功能**：
  * `OESCameraFilter`：负责将 Android 特有的 OES 硬件纹理转换为标准的 RGB 纹理。
  * `GrayscaleFilter`：作为特效演示，将彩色画面实时转换为灰度画面。
* **特性亮点**：支持 FBO (Framebuffer Object) 乒乓缓冲调度，可无限叠加任意数量的滤镜而不破坏渲染管线。

### 2.3 硬件加速双轨录制与导出 (Hardware Media Export)
* **功能描述**：一键将当前带有特效的画面和麦克风收录的声音，混合封装为标准的 `.mp4` 文件。
* **特性亮点**：
  * **H.265/H.264 动态协商**：优先尝试利用设备的硬件编码器压缩 H.265 (HEVC) 视频，以获得极高的压缩比和画质；若设备不支持，则自动降级为兼容性极佳的 H.264 (AVC)。
  * **后台静默导出**：借助“多目标渲染”技术，导出过程不仅所见即所得，且不干扰主屏幕的正常显示。

### 2.4 低延迟麦克风采集 (Low-Latency Audio Capture)
* **功能描述**：录像时自动采集设备的麦克风声音。
* **特性亮点**：使用 Google `Oboe` 底层库，以 `48kHz` 采样率、双声道 `16-bit PCM` 的高规格捕获音频，并通过独立线程推送至 AAC 硬件编码器，确保口型与画面绝对同步。

## 3. UI 交互层 (Android Jetpack Compose Demo)
工程自带一个完全基于最新 Jetpack Compose 构建的 Android 示例程序，提供了以下体验级功能：
* **沉浸式主页**：草稿箱列表、工具箱入口（仅 UI 占位）。
* **拍摄面板**：提供全屏实时特效预览、翻转镜头、倒计时等功能按钮，并附带动态状态切换的悬浮录制按钮。
